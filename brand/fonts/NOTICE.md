# Fonts

These files are used only at build time, to convert the wordmark to outline
paths. The published logo files contain no font data.

| File | Family | Source | License |
| --- | --- | --- | --- |
| `rye.woff2` | Rye | Google Fonts | SIL Open Font License 1.1 |
| `yellowtail.woff2` | Yellowtail | Google Fonts | SIL Open Font License 1.1 |
| `oswald-600.ttf` | Oswald, instanced at weight 600 | Google Fonts | SIL Open Font License 1.1 |

The OFL permits outlines derived from these faces to be used in a logo, with no
attribution required on the artwork itself. Full license text:
https://openfontlicense.org/open-font-license-official-text/

Oswald ships as a variable font; `oswald-600.ttf` is a static instance produced
with `fontTools.varLib.instancer` at `wght=600`.
